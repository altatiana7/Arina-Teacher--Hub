# Arina-Teacher--Hub

## Домашка по датам уроков (с 14.11.2026)

Уроки Арины: понедельник, среда, суббота. Каждая новая домашка = одна запись в начале `ARINA_HW_LIST` в файле `hw-list.js`
(`given` — день выдачи, `tasks` — id задания, название, тип). Даты «урок» и «сдать к» считаются сами.
Этот же файл читает учительский сайт (EGE-train-for-teacher, карточка «Домашка Арины»), поэтому задание, которого нет в `hw-list.js`,
учитель на главном экране не увидит. Экран «Домашка» у Арины рисует `hw-board.js`.
